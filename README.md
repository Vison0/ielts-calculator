# IELTS Band Score Calculator (Free, Offline)

Free, open-source IELTS band score calculator. No APIs, no tracking — pure HTML/CSS/JS so it runs anywhere, including GitHub Pages.

Features ported from the Band9Prep calculator:
- **Overall Band Calculator** — average of Listening / Reading / Writing / Speaking, rounded to nearest 0.5 (official IELTS rule)
- **Raw Score Converter** — correct answers (0–40) → band for Listening, Academic Reading, General Training Reading
- **Official conversion tables** included on-page
- FAQ + responsive mobile layout

## Use it

Just open `index.html`, or serve the folder:

```bash
npx serve .
```
